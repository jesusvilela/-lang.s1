# §-LANG Structured Claim Interface

This is the primary evidence-backed entry point for the §-LANG framework.

Instead of making unbounded claims about "solving NP-completeness" or "realizing Lafforgue unification," this interface strictly bounds the project's truth to its empirical validations:

1. **Geometric Invariants:** Claims of hyperbolic limits are backed by strict programmatic checks on every coordinate section via `validate_typecast.py`.
2. **Execution Reality:** The `RUNTIME_CAPABILITIES` manifest separates what the system actually computes (e.g. colimits, Loeb recursion) from what is merely symbolically encoded (e.g. Selberg trace formulas).
3. **Formal Proof Boundary:** Acknowledging that the system is currently a geometric hypothesis rather than an automated theorem prover.

See `TOPOS_AI_PROOF.md` for the explicit operational proof of these definitions.
